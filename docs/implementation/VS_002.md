# VS-002: continuous conversations, local history, and model settings

Status: source implemented; target-Mac visual acceptance pending

Date: 2026-08-04

## Outcome

VS-002 keeps Evie's normal surface compact while removing the one-question
prototype boundary:

- launching the shell opens the quick-text field already focused;
- `Option-Space` opens or hides that field, and `Option-Shift-Space` remains a
  temporary secondary text shortcut;
- after a response, its artifact card remains visible and a fresh field returns;
- every completed user/assistant turn is saved locally and can be resumed after a
  restart;
- the menu-bar item exposes conversation, new-session, history, show/hide,
  settings, endpoint status, and quit actions;
- a deliberate history window lists sessions, displays their visible messages,
  resumes them, and confirms deletion;
- a settings window edits temperature, top-p, completion limit, and timeout,
  persists them to the established local JSON, and applies them to the next turn.

This slice does not implement wake word, microphone capture, STT, TTS playback,
RAG, web search, filesystem tools, Hermes, or semantic memory. UI labels and the
system prompt state that boundary explicitly.

## Storage contract

Conversation records live outside Git at:

```text
~/Library/Application Support/Evie/Conversations/<uuid>.json
```

The directory is `0700`; records are `0600`. Each record has schema version 1,
stable IDs, a normalized title, timestamps, and visible messages. Hidden
`system`/`developer` prompts are stripped before persistence and rejected if
injected into a stored file. Writes use a same-directory temporary file and atomic
rename. Index scanning skips an individually malformed/unavailable record, keeps
readable conversations visible, and exposes only an opaque count; directly opening
that record still fails closed without echoing its content.

The complete visible transcript is retained for history. The request builder
independently removes the oldest complete turns from a copy when the configured
model budget would be exceeded. Persisted history therefore is not silently
truncated to fit one inference request.

See [ADR 0008](../adr/0008-local-conversation-history.md).

## Local acceptance checklist

With the existing server ready, launch the release shell:

```bash
Scripts/evie-runtime launch
```

Verify manually:

1. the first field appears focused without a shortcut;
2. send two related questions in sequence and confirm the second can refer to the
   first;
3. confirm the first card remains accessible while the next field is shown;
4. use `Option-Space` to hide and reopen the field;
5. use the menu to create a new conversation;
6. open History, resume the earlier session, and ask a follow-up;
7. close/relaunch Evie and confirm the session remains in History;
8. attempt a history deletion and confirm no deletion occurs before the explicit
   destructive button;
9. change temperature, save, reopen settings, and confirm the local config remains
   mode `0600`;
10. check focus behavior if the response finishes after switching to another app.

The last item remains especially important: automatically restoring the field is
intentional for rapid follow-ups, but target testing must decide whether that
focus policy is too aggressive for longer asynchronous tasks.

## Automated validation

The deterministic suite covers:

- conversation create/list/load/save/delete;
- newest-first stable ordering and serialized concurrent mutations;
- schema, timestamp, identifier, duplicate-message, malformed-record, and hidden
  prompt rejection;
- readable-session containment and an opaque unavailable count when another record
  is corrupt;
- atomic replacement without leftover temporary files;
- user-only conversation/configuration permissions;
- configuration save/load round-trip and validation-before-write;
- all previous TurboFieldfare/SSE fixtures.

Use:

```bash
swift format lint --strict --recursive Sources Tests
Scripts/test
swift build -c release --product evie-shell -Xswiftc -warnings-as-errors
```

Command Line Tools may still emit the already documented external linker
search-path warnings; Swift source warnings remain failures.

At the source handoff, all 46 deterministic tests across six suites passed, strict
format lint passed, and the release `evie-shell` product built with warnings treated
as errors. The rebuilt shell was then relaunched against the existing healthy
loopback server, whose model-discovery, non-streaming, and SSE `[DONE]` smoke checks
passed again. Rendered focus/history/settings behavior remains the manual checklist
above rather than an automated claim.
